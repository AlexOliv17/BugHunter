# BugHunter

Plataforma educacional de depuração: o aluno aponta a linha do defeito de uma função Python quebrada de propósito, corrige o código e recebe feedback.

| Pasta       | Conteúdo                                              |
|-------------|-------------------------------------------------------|
| `/app`      | aplicação Next.js (App Router, TypeScript)            |
| `/pipeline` | mutadores AST e carga do banco (Python, roda offline) |
| `/supabase` | migrations SQL                                        |
| `/docs`     | documentos do projeto                                 |

Instruções de ambiente, pipeline e publicação entram na atividade S6-05.
